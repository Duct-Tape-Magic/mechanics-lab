How to use Mechanics Lab

A 2D sandbox for classical mechanics. Everything is in SI units: metres, kilograms, seconds, newtons.

  • Add objects from the left menu, or load one of the experiments.
  • Drag an object to move it. While the simulation runs, dragging and releasing throws it.
  • Set velocity by dragging the arrow tip of the selected object while paused, or type values in the inspector.
  • Pendulums and springs are a mass plus a rod or spring. Select the mass to edit length, angle, stiffness and damping. A rod or spring can attach to a fixed point or to another object, so you can build a double pendulum or coupled masses.
  • Reset returns to the starting state. Set as start makes the current state the new starting point.
  • Share link copies a URL that recreates the current scene.
